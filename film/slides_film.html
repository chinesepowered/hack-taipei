AI 技術與製作流程

生成

  • GMI Cloud · Wan 3.0 Video Prime，1080P，15 秒／鏡
  • 7 鏡 image-to-video：官方設定稿裁切、補成 16:9 當第一幀，角色造型不跑
  • 2 鏡純文字：高密度造型描述 + negative prompt 鎖服裝
  • 固定 seed，每一鏡可重現

管線（開源）

  • 分鏡 JSON → 一次批次送出 → 輪詢 → 下載 → ffmpeg 串接、套歌、淡出
  • request id 即時落盤：當機不重複計費，可續跑
  • 版本紀錄：01 因裁切重做、02 過審改寫、07 卡住重送，全部留檔
  • 創作理念 PDF 由同一份資料自動產生
