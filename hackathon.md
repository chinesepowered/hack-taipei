## Rules

1. 1–5 per team, one main team per person.
2. Valid ticket required.
3. Daily check-in 09:00–16:00, all three days.
4. **Open source is mandatory** for overall ranking: public repo, README, license file, run instructions.
5. **One main work per team, one main track.** The same work can compete for the overall ranking AND multiple sponsor prizes if it meets their eligibility.
6. Pre-built work is allowed in general tracks, but you must fully disclose existing code, models, data, and third-party assets used. Creative track (04) on-site material has separate rules.
7. IP stays with the team, but sponsor/organizer IP (NOXCAT, 科幻協會 characters, music) is subject to their license terms.

## Submission contents (due 9/6 10:00)

1. Team info, main track, sponsor challenges entered
2. 100–200 word problem + solution summary
3. Public GitHub/GitLab repo with license file
4. README, system architecture, how to run, source/attribution of assets
5. Demo URL (optional)
6. **YouTube judging video, max 2 minutes**

README template and submission checklist are downloadable from the Resources section on the site.

## Strategy notes derived from the above

1. **Overall top 3 is 70% of the money.** Optimize for Round 1 first (video + repo + README), because nothing else matters if you miss the top-10 cut.
2. **Sponsor prizes stack.** A project that qualifies for Cathay or NOXCAT adds US$1,500 upside AND buys a friendly judge in Round 2 (2 of 5 judges are those sponsors).
3. **Track 04 film is an add-on** with a US$3,000 pool and a 9/5 noon deadline. Likely low competition because it needs a 1.5-min film made in about one day. A team of 3+ could split one person onto it.
4. **Open source and attribution are hard requirements.** MIT license + clear README + a "what was pre-built" section.
5. **Topic lock is 9/4 16:30.** Decide track today.
6. The 2-minute video must show the emotional hook in the first 15 seconds, the working product by 0:45, and the architecture in one diagram.
